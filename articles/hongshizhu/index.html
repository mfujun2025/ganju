柑橘红蜘蛛绿色防治技术

红蜘蛛是柑橘第一大虫害，靠阈值用药、药剂轮换和保护天敌实现绿色防控，而非见虫就打。

柑橘红蜘蛛（柑橘全爪螨）以成螨、若螨刺吸叶片汁液，被害叶片失绿呈灰白色小点，严重时落叶落果。年发生 12—20 代，春秋两季为高峰，是柑橘产区常年监测的第一大虫害。

一、发生规律

红蜘蛛喜欢温暖干燥，20—30℃ 繁殖快，高温多雨抑制其发展。它体积小、繁殖快、世代重叠，单一药剂连续使用 2—3 次就容易产生抗药性。很多果园越打药越爆发，根源在于滥用广谱杀虫剂杀死了捕食螨、食螨瓢虫等天敌。

二、监测与阈值

不要见虫就打。定期查叶：每片叶平均螨量达到当地植保部门规定的防治指标（一般每叶 3—5 头，视品种和生育期调整）时才用药。重点查叶背和内膛枝，这些地方虫口密度高。

三、绿色防控措施

1. 保护天敌。 推行果园生草栽培，保留霍香蓟、白三叶等浅根绿肥，为捕食螨提供栖息环境。少用拟除虫菊酯等广谱杀虫剂，避免误杀天敌。有条件的果园可人工释放捕食螨。

2. 药剂轮换。 不同作用机理的药剂轮换使用，同一类药一个梢期最多用一次。喷药时叶背、叶面、内膛都要喷匀喷透，瞒虫躲在叶背，喷不到位等于白打。

3. 关键窗口期。 春秋高峰前、新梢期是重点预防阶段。冬春清园时喷石硫合剂，压低越冬基数。

4. 物理与生物辅助。 挂黄板监测，高温干旱期注意灌溉降温，改善果园小气候。

四、常见错误

  • 一味加量、加次数，把天敌杀光，螨虫反弹更猛；
  • 只喷叶面不喷叶背，虫源未除；
  • 一种药从头用到尾，抗药性越来越重。

具体药剂选择、浓度与安全间隔期以当地植保站推荐为准。
